# Diagonal War

**2-4 人回合制策略棋盤遊戲** | Rust + Bevy 0.19

> 放掉越多棋子越好。不是看佔領面積，也不是最後存活。

---

## 遊戲規則

### 目標
所有玩家皆無法再合法放置棋子時遊戲結束，剩餘未放置棋子的**總格數最少者獲勝**。

### 棋盤
- 20 × 20 正方形棋盤
- 每位玩家固定一個起始角（左上、右上、右下、左下）

### 棋子
- 每位玩家持有相同的 **21 塊 Polyomino 棋子**（共 89 格）
- 棋子可旋轉（90°/180°/270°）與鏡像翻轉

### 放置規則
1. **第一步**：必須覆蓋自己的起始角
2. **後續放置**：
   - 至少一個角與自己棋子角相接 ✅ (`□■`/`■□`)
   - 不可與自己棋子邊接觸 ❌ (`■■`)
   - 可與其他玩家邊接觸 ✅
   - 不可重疊、不可超出棋盤
3. **淘汰**：輪到自己時無合法放置 → 淘汰（記錄淘汰順序）
4. **結束**：僅剩 1 名活躍玩家 → 該玩家獲勝

### 排名
1. 未淘汰者（Winner）最優先
2. 越晚淘汰排名越高
3. 同時淘汰者比剩餘格數（越少越高）

## 安裝與執行

### 需求
- Rust 穩定版（2024 edition）
- Windows / macOS / Linux

### 執行
```bash
git clone https://github.com/adamliang981011/diagonal-war-game.git
cd diagonal-war
cargo run --release
```

### 測試
```bash
cargo test --lib
```

## 操作說明

| 操作 | 按鍵 |
|------|------|
| 選擇棋子 | 點擊右側面板的棋子卡片 |
| 旋轉 | `R` |
| 鏡像 | `M` |
| 放置 | 左鍵點擊棋盤位置 |
| 取消選擇 | 點擊其他棋子 |
| 選單滾動 | 滑鼠滾輪 |

## 架構

```
src/
├── game/       # 純遊戲邏輯，無 Bevy 依賴（可獨立測試）
│   ├── board.rs         # 棋盤與放置驗證
│   ├── piece.rs         # 棋子定義與幾何變換
│   ├── piece_library.rs # 21 個 Blokus 風格棋子
│   ├── player.rs        # 玩家狀態（淘汰順序追蹤）
│   ├── rules.rs         # 合法移動搜尋
│   └── scoring.rs       # 排名計算
├── ai/          # AI 策略
│   └── greedy.rs        # 貪婪 AI
├── ui/          # Bevy 渲染與互動
│   ├── board.rs         # 棋盤渲染與放置互動
│   ├── panel.rs         # 棋子選擇面板（2 欄卡片）
│   ├── menu.rs          # 遊戲選單
│   └── hud.rs           # HUD、控制、遊戲結束
├── state/       # 遊戲狀態機
│   └── mod.rs           # GameResource / GameConfig
├── main.rs      # 應用程式入口
└── lib.rs       # 模組匯出
```
